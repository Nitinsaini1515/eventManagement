# CampusConnect -- Event Management Portal

CampusConnect is a modern college event discovery and management portal
built with **React** and **Tailwind CSS**. It provides students with a
simple and attractive interface to discover upcoming campus events,
explore event details, and stay connected with college activities.

## 🚀 Features

-   🎓 College-focused event discovery
-   🔎 Browse and explore campus events
-   🗓️ Event details with date, time, venue, and description
-   🏷️ Event categorization such as Sports, Academic, Cultural,
    Technical, etc.
-   📱 Responsive design for desktop and mobile screens
-   🧩 Reusable React components
-   🎨 Modern UI built using Tailwind CSS
-   📋 Event cards and detailed event modal
-   ⚡ Fast development setup using Vite

## ⚙️ Installation & Setup

### 1. Clone the repository

``` bash
git clone <YOUR_REPOSITORY_URL>
cd eventManagement
```

### 2. Go to the frontend folder

``` bash
cd frontend
```

### 3. Install dependencies

``` bash
npm install
```

### 4. Start the development server

``` bash
npm run dev
```

The application will be available at the local URL shown in the
terminal, usually:

``` text
http://localhost:5173
```

## 🧑‍💻 Development
